# 50ETF 完整认购实验运行说明

入口为本目录的 `run_full.ps1`。本次配置见 `experiment.json`，市场和对冲分别使用 Python 3.9.25 与 Python 3.13.12。安装交付区参数与依赖目录中的对应清单。作者代码使用 `vicaws/neuralSDE-marketmodel` 的 `6fa18790f14b56c99407ef987406459fa6e3b988` 提交。

在 PowerShell 中传入未复权 50ETF 现货 CSV、期权日线 CSV、两套 Python、作者仓库位置，以及本地数据和结果目录。

```powershell
& ./run_full.ps1 -OptionFile '<期权 CSV>' -SpotFile '<现货 CSV>' `
  -MarketPython '<市场 python.exe>' -HedgePython '<对冲 python.exe>' `
  -Upstream '<作者代码目录>' -DataDir '<本地数据目录>' -ResultDir '<结果目录>'
```

同一输入和配置可复用已完成阶段及已完成策略训练。更改输入或配置时使用新数据目录。输入哈希文件按期权、现货、配置排列。数据目录保存完整清单、每日条款、模拟路径、市场权重和各组对冲权重与账本。

三档入场窗口为 15–30、45–60、75–90 自然日。在每个数据区间和期限档内，每张合约选首次合格交易日。价内、平值、价外按初始 K/S 相对 0.97 和 1.03 划分。训练采用 2015–2022 年，2023 年真实验证 RMSE 选择权重，2024–2025 年进行比较。BS 反解失败时沿用前次有效隐波，初始缺失用 25%。

策略计算采用理想化同收盘交易。现金利率为零。真实账本计入分红及合约调整，生成器使用连续市场近似。汇总表将每个种子的指标分别计算后取均值，损益除以期初 ETF 名义金额。CVaR95 取最差 5% 损失的经验加权均值。
