# 50ETF 创新组合实验

本程序登记 1,008 个策略训练条目。先完成所有验证选择，再读取历史评价路径生成汇总。
2024–2025 是已观察的历史评价。三个滚动折的评价年份为 2021、2022、2023。
原始行情、详细路径及权重留在本地。

在 Windows PowerShell 运行，传入期权日线和未复权 50ETF 日线：

```powershell
& ./run_study.ps1 -OptionFile '<期权 CSV>' -SpotFile '<未复权现货 CSV>'
```

可用 `-MarketPython`、`-HedgePython`、`-Upstream`、`-DataDir`、`-OldData` 指定环境和数据位置。
默认复用同仓库完整认购的基础代码和原有环境。市场环境 Python 3.9／TensorFlow 2.9.1，
策略环境 Python 3.13／PyTorch 2.12.1 CPU。依赖清单沿用交付区的 market-requirements.txt
和 hedge-requirements.txt。作者固定提交为 6fa18790f14b56c99407ef987406459fa6e3b988。

`-PrepareOnly` 只生成市场产物。同一配置重跑会核验产物与依赖哈希并继续执行。
后台运行时查看处理后数据目录中的 study.stdout.log、study.stderr.log 和各策略状态 JSON。
完整训练时间按本机实测记录。原版回放需要完整认购的原权重和原逐日账本。

结果位于数据目录的 evaluation 下。启动本地结果页：

```powershell
& '<对冲 Python>' ./dashboard.py '<实验数据目录>'
```

访问 http://127.0.0.1:8765 。结果页只从本地读取已保存产物。

完成后用 `deliver.py <实验数据目录> <代码根目录>` 交付到本地。
加 `--publish` 同步程序、配置、汇总和图表到已配置的仓库。交付入口要求 1,008 个登记条目逐项有结论。滚动折若不足两个合格市场，按预登记规则将相应条目标为不可运行并公开计数。其余条目通过验收后交付。
