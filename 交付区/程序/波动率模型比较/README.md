# 50ETF 经典波动率模型与 Neural SDE 比较

本目录实施九市场、四研究折、432项策略训练。全部旧实验独立保留。本轮尚不能由已完成的单元检查推断哪种模型对冲更好。

## 一次运行

在项目根目录，使用已建立的独立环境运行：

```powershell
& '工作区/运行支持/环境/volatility/Scripts/python.exe' -u '工作区/当前研究/程序/波动率模型比较/run_pipeline.py'
```

入口顺序为共同报价核验、原曲面与各折编码、每日经典曲面、市场拟合与模拟、三种子训练、冻结策略的真实回放与配对区间、直接对冲与审计、交付。TensorFlow 阶段使用既有 market 环境；策略及分析使用 volatility 环境。依赖快照随程序保存。

登记清单为9市场×2信息集×2目标×4研究折×3种子，共432项。每市场40960条模拟路径中前32768条用于策略训练，后8192条保留。策略仅按真实验证年选检查点，历史评价损益随后统一生成。

重复启动会先取得独占锁。复用前核对数据、源码、父产物、初态及权重哈希。旧的失败记录不会压过后来合格的生成器。异常时结束本次入口创建的子进程，避免留下重复写者；修复后重新执行同一入口。被替换的试算放在输出目录 attempts 中。

## 文件位置与状态

- 输出根目录：`工作区/数据/处理后/波动率模型比较`。
- `coordinator.json`：当前阶段；`coordinator_failure.json`：入口异常。失败记录不能当作完成。
- `queue_seed*.json`：各种子的真实队列；`policies/*.progress.json`：验证轨迹。
- `acceptance_manifest.json`：强制检查全部必需阶段。缺审计、缺对照或基础设施失败均不能交付完成。
- `evaluation/seed_summary.csv`：各方法的三种子均值与范围。
- `evaluation/surface_comparison.csv`：完整报价与独立留报价的价格/IV误差；保留域内、短期限、翼部与期限外分组。
- `evaluation/paired_intervals.csv`：共享到期月块抽样的配对区间。
- `evaluation/numerical_diagnostics.csv`、`compute_costs.csv`：实际数值近似与计算量。

模型、逐路径损益与逐日账本留本地。验收后复制程序、配置、模型和汇总到交付区；GitHub只接收经过白名单审核的程序与聚合结果。

## 比较的解释范围

新实验统一使用相同清洗报价重建原20格点，再重新拟合训练期C1两因子与原作者非线性联合SDE。旧C0/C1只作历史参照，其清洗、输入和初始化与本轮不同，不作纯模型归因。

Heston/SABR的定价与历史漂移分开，扩散参数跨测度一致。局部波动率使用起点eSSVI导出的120日表及训练期历史漂移；途中不读取未来真实曲面。

有限格点可行、逐日静态约束与完整动态无套利不是同一性质。两子步与配对四子步只作数值诊断，不证明策略对步长不敏感。预测诊断复用训练起点及存储情景，明确属于训练内部诊断，不能当作独立时间外预测证据。

2024–2025已经被研究观察，称为历史评价集。滚动折也为历史证据；大量探索比较没有多重检验调整。RMSE、尾部损失、成本与速度分别展示，区间跨零写证据有限，不强行选总冠军。
